# Minecraft Web Edition

A simple Minecraft-style game that runs in your browser. Explore a block world, collect resources, craft items, build structures, and survive.

## Play online

[**Play now →**](https://minecraft-web-2nn.pages.dev/)

No download or installation needed.

## Features

- Procedurally generated block worlds
- Survival and Creative modes
- Mining, building, crafting, and smelting
- Inventory, chests, trading, and enchanting
- Mobs, health, hunger, weather, and day/night cycles
- Desktop and touch controls
- Adjustable graphics, audio, and performance settings

## Controls

- `W` `A` `S` `D` — move
- `Space` — jump
- `Shift` — sneak
- Mouse — look around
- Hold left click — mine blocks
- Right click — place blocks or interact
- `1`–`9` / mouse wheel — choose an item
- `E` — open inventory
- `Q` — drop an item
- `C` — change camera view
- `F` — fly in Creative mode
- `Esc` — pause
- `F3` — show debug information

Touch controls can be enabled in **Options → Touch & Controls**.

## Run locally

Install Node.js, then run:

```sh
npm install
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

Other commands:

```sh
npm test        # run tests
npm run build   # create a production build
npm run preview  # preview the production build
```

## Built with

TypeScript, Vite, Three.js, WebGL, and Web Audio API.

## Status

This is an independent, single-player browser project. It is still being developed and does not include multiplayer. World and gameplay data are not yet fully saved between sessions.
